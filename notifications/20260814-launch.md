# 新项目案例上线

🎉 新项目案例已上线，涵盖前端工程、数据看板、个人门户等方向。

## 更新内容

本次新增以下项目案例：

### 前端工程

CLI 脚手架工具，支持快速初始化项目结构，内置 TypeScript、ESLint、Prettier 等工程化配置，一键生成开箱即用的开发环境。

### 数据看板

基于 Vue 3 + ECharts 的数据可视化看板，支持多维度数据筛选、实时刷新与自定义图表组合，适用于运营监控与业务分析场景。

### 个人门户

使用 VitePress 搭建的个人门户站点，内容由 Markdown 驱动，涵盖项目展示、个人简介与联系方式，支持暗色模式与全文搜索。

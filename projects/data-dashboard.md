# 数据可视化看板

## 背景

运营团队需要每天盯着十几个数据指标，分散在多个后台，效率很低。目标是一个聚合所有关键指标的实时看板，开屏即见。

## 技术选型

- **前端**：Vue 3 + Composition API，ECharts 5 渲染
- **后端**：Node.js + Koa，WebSocket 推送实时数据
- **数据源**：MySQL / Redis / 第三方 API 聚合

## 我的职责

- 设计可配置的图表编排协议，运营可拖拽组合指标
- 实现数据源适配层，新增数据源只需实现统一接口
- 优化大数据量下的渲染性能，使用增量更新避免全量重绘

## 成果

- 看板首屏加载从 3.2s 降到 1.1s
- 覆盖 12 个业务线、80+ 指标
- 日活运营用户 200+
